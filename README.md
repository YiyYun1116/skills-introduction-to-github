# 溯源 · Signal Atlas

中文金融信息分析工作台：公开来源自动采集、重复内容过滤、主题聚合、证据追溯、公司申报索引、论文与条件情景分析。支持股票、期货、期权、加密资产和宏观的分类与关注列表。

这是可运行的首版，不宣称已连接全球所有平台、覆盖所有证券或能够自动证明新闻为真。真实采集数据与虚构演示数据完全分离；行情与期权链尚未接入。

## 手机和电脑直接使用

已准备 Render 网站部署配置，包含访问密码和持久化数据库；HTTPS 由托管平台提供。**尚未部署网站**，实际网址会在你创建托管服务后显示。

最少操作步骤见 [手机与浏览器上线指南](docs/DEPLOY.md)：注册 Render → 从本仓库的 `signal-atlas-web` 分支创建 Blueprint → 确认费用并部署。完成后手机和电脑使用同一个 HTTPS 地址，无需购买域名。Starter 服务和持久盘是收费资源，费用以创建页面为准。

## 启动

需要 Python 3.12+。在仓库目录执行：

```bash
bash scripts/install.sh
bash scripts/start.sh
```

服务默认监听本机 8000 端口。可通过 `SIGNAL_ATLAS_PORT` 指定端口。在自己的电脑启动时可访问本机端口；此云环境的 onboarding 界面不提供该网页的公网预览，手机访问需要按上面的 Render 步骤部署。网站托管使用 `python scripts/serve.py`，生产模式要求设置访问密码。

```bash
curl --fail http://127.0.0.1:8000/api/health
bash scripts/check.sh
```

无前端构建步骤。界面资源全部本地加载，不依赖外部字体/CDN。文档 API 由 FastAPI 提供。

## 当前功能

- 13 个已验证订阅格式的公开来源：美联储公告/讲话、欧洲央行、英格兰银行、国际清算银行、日本银行、SEC 新闻、SEC 年报/季报索引、arXiv 金融/经济论文、BBC 与 Guardian 商业新闻。媒体标题与摘要标为二手报道，仍需结合原始公告核验。历史格式验证不保证当前连通；最近结果以“数据来源”页为准。
- “公司财报”页展示美国 SEC EDGAR 的 10-K 年报、10-Q 季报索引，可能包含 10-KT / 10-QT 过渡报告及 `/A` 修订。保留公司名称、CIK、申报编号、类型、受理时间与原始链接；未从全文提取营收、利润、现金流等指标。
- 每个 SEC 订阅每轮最多读取最近 100 条，尚无历史回补；高峰期可能漏掉两轮之间被订阅窗口覆盖的申报。当前不是全球公司财报库，受理时间也不等于报告覆盖期间。SEC 收录不代表为公司披露担保。
- 首次打开默认真实数据模式；空库显示等待采集，失败时显示原因。演示数据仅在主动切换后展示。
- URL、标题及正文线索用于去重，保留重复内容与出处。独立来源数量按来源组计算，不以转载次数替代交叉证据。
- 主题聚合展示来源依据、证据局限及原始链接；来源证据评分不是事实为真的概率。相关内容仍可能存在矛盾，需阅读原文核对。
- 情绪是透明的新闻措辞词典指标，不是交易者持仓、全市场情绪或实时行情。
- 研究页集中论文条目及可用摘要。预印本不代表同行评审；首版没有“顶尖人才”自动排名、全文阅读或因果推断能力。
- 论文首次发表、订阅公告、修订时间分别保留。arXiv RSS 的修订公告不冒充新论文发表；原始日期未知时明确显示未知。
- 条件情景列出观察变量与上行/基准/下行情形，不提供未经回测的概率、价格目标或确定收益。
- 关注列表保存在 SQLite，支持全球资产符号与备注。代码录入是用户自定义条目，未校验上市/合约状态，不提供虚构报价。
- 资产关联按名称/代码边界、资产类型与地区筛选，仅标为待复核候选。来源统计按机构分组，多个美联储订阅不会被算作多家独立机构。
- CSV 导出保留演示/实时标识，并处理表格公式注入。
- 主题、论文和公司申报列表每次展示 30 条，可加载更多；搜索与筛选覆盖接口已加载的全部资料，避免手机一次渲染大量卡片。

## 自动采集与存储

服务启动约 3 秒后尝试同步已启用来源，每轮结束约 30 分钟后再次采集。关闭浏览器不影响后台采集；服务停止期间不会更新，也不会自动回补停机期间的全部材料。`SIGNAL_ATLAS_SYNC_MINUTES=0` 关闭自动采集，仍可手动同步；其他值最小为 5 分钟。保持单实例、单 worker，自动与手动采集不会在同一进程中重叠运行。

超时、连接中断、HTTP 408 / 429 / 5xx 等暂时错误可有限重试，每个来源每轮最多 3 次读取尝试。HTTP 403 / 404、网络策略拒绝、TLS 校验失败及解析错误不在本轮重试；较长的 `Retry-After` 会结束本轮尝试并保留原因。后续轮次继续检查，已有材料不会因来源暂时失败而清空。

“数据来源”页显示下次计划、最近成功读取、连续失败次数及采集记录。每轮分别记录：

- **新收录**：本平台首次保存，不代表原文刚刚发表。
- **内容修订**：已存条目的内容发生变化；不等同于 SEC 的 `/A` 修订申报类型。
- **无变化**：已存内容被再次读取，不重复计为新增。

资料、每轮计数和来源状态在同一数据库事务中保存，避免中途重启造成统计错位。数据库保留最近 100 次采集记录，仪表盘接口返回最近 20 次，界面展示最近 5 次。重启后未结束的旧任务标为中断，并重新安排采集。

SQLite 默认路径 `.local/signal-atlas.sqlite3`（Git 忽略），`SIGNAL_ATLAS_DB` 可指定其他路径。数据库保存真实条目、采集状态、有限采集历史和关注列表。演示条目不入库，使用固定的 2026-01-15 时间和明确的虚构来源。面板及系统检查最多读取最近 2,000 条资料；这不是全历史检索或完整回测系统。

## 系统检查与网络

“数据来源 → 系统检查”检查调度器、数据库读取、最近来源状态与读取时效，以及当前资料窗口中的演示标记、登记来源链接、日期和覆盖缺口。检查不会重新探测所有外部网站，也不能证明新闻真实、财报数字正确或投资结论成立。`/api/health` 只检查应用和数据库就绪，不代表采集成功。

源目录位于 `app/sources.py`。当前环境需要允许目录中指定的官方 HTTPS 域名。添加来源时先确认使用条款、许可、发布时间语义、原始作者与转载关系，并注册精确主机名；浏览器不会代理任意用户提供的 URL。

所需来源主机：`www.federalreserve.gov`、`www.ecb.europa.eu`、`www.bankofengland.co.uk`、`www.bis.org`、`www.boj.or.jp`、`www.sec.gov`、`export.arxiv.org`、`rss.arxiv.org`、`feeds.bbci.co.uk`、`www.theguardian.com`。当前只读取已登记公开订阅，不下载付费全文或绕过访问限制。

Codex 开发环境的安装、启动与来源网络设置已保存到配置草稿，另有 4 个候选新闻域名的追加设置；仍需在环境设置中审核、保存并发布。草稿不代表运行实例已经放行。**开发环境发布与 Render 网站上线是两件事**：手机访问需要完成 Render 部署，开发环境的域名规则不会自动配置到 Render。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/dashboard?mode=live` | 实时库聚合结果，空库保持为空 |
| `GET /api/dashboard?mode=demo` | 明确标识的虚构演示数据 |
| `GET /api/diagnostics` | 当前服务、最近采集记录与资料窗口的只读检查 |
| `POST /api/ingest` | `{}` 同步启用来源，或 `{"source_ids":["来源 ID"]}` |
| `GET /api/watchlist` | 读取关注资产 |
| `POST /api/watchlist` | 保存 symbol/name/asset_class/region/note |
| `DELETE /api/watchlist/{id}` | 删除关注项 |
| `GET /api/export?mode=live` | 导出当前主题摘要 |
| `GET /api/health` | 应用和数据库就绪检查 |
