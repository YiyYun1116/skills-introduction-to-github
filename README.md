# 溯源 · Signal Atlas

中文金融信息分析工作台：公开来源采集、重复内容过滤、主题聚合、证据追溯、新闻措辞情绪、论文与条件情景分析。覆盖股票、期货、期权、加密资产和宏观的分类与关注列表。

这是可运行的首版，不宣称已连接全球所有平台、覆盖所有证券或能够自动证明新闻为真。真实采集数据与虚构演示数据完全分离；行情与期权链尚未接入。

## 手机和电脑直接使用

已准备 Render 网站部署配置，包含访问密码、HTTPS 托管入口配置和持久化数据库。**代码仓库不是已上线的网站**；实际网址会在你创建托管服务后显示。

最少操作步骤见 [手机与浏览器上线指南](docs/DEPLOY.md)：注册 Render → 从本仓库的 `signal-atlas-web` 分支创建 Blueprint → 确认费用并部署。完成后手机和电脑使用同一个 HTTPS 地址，无需购买域名。Starter 服务和持久盘是收费资源，费用以创建页面为准。

## 启动

需要 Python 3.12+。在仓库目录执行：

```bash
bash scripts/install.sh
bash scripts/start.sh
```

服务默认监听本机 8000 端口。可通过 `SIGNAL_ATLAS_PORT` 指定端口。此云环境的 onboarding 界面不提供本地网页预览；可在支持端口转发的开发环境使用，或把代码运行在自己的机器上。网站托管使用 `python scripts/serve.py`，生产模式要求设置访问密码。

```bash
curl --fail http://127.0.0.1:8000/api/health
bash scripts/check.sh
```

无前端构建步骤。界面资源全部本地加载，不依赖外部字体/CDN。文档 API 由 FastAPI 提供。

## 当前功能

- 9 个原始订阅来源：美联储公告/讲话、欧洲央行、英格兰银行、国际清算银行、日本银行、美国证监会、arXiv 金融/经济论文。网络、解析或来源不可用时保留具体错误，不生成替代“实时新闻”。
- URL、标题及正文线索用于去重，保留重复内容与出处。独立来源数量按来源组计算，不以转载次数替代交叉证据。
- 主题聚合展示来源依据、证据局限及原始链接；来源证据评分不是事实为真的概率。相关内容仍可能存在矛盾，需阅读原文核对。
- 情绪是透明的新闻措辞词典指标，不是交易者持仓、全市场情绪或实时行情。
- 研究页集中论文条目及可用摘要。预印本不代表同行评审；首版没有“顶尖人才”自动排名、全文阅读或因果推断能力。
- 论文首次发表、订阅公告、修订时间分别保留。arXiv RSS 的修订公告不冒充新论文发表；原始日期未知时明确显示未知。
- 条件情景列出观察变量与上行/基准/下行情形，不提供未经回测的概率、价格目标或确定收益。
- 关注列表保存在 SQLite，支持全球资产符号与备注。代码录入是用户自定义条目，未校验上市/合约状态，不提供虚构报价。
- 资产关联按名称/代码边界、资产类型与地区筛选，仅标为待复核候选。来源统计按机构分组，多个美联储订阅不会被算作多家独立机构。
- CSV 导出保留演示/实时标识，并处理表格公式注入。

## 自动采集与存储

启动后尝试同步已启用来源，默认每 30 分钟重复。`SIGNAL_ATLAS_SYNC_MINUTES=0` 关闭自动采集，仍可在界面手动同步；其他值最小为 5 分钟。单次采集采用有限超时和并发，重复同步按稳定 ID 更新。建议单 worker 运行，避免重复调度。

SQLite 默认路径 `.local/signal-atlas.sqlite3`（Git 忽略）。`SIGNAL_ATLAS_DB` 可指定其他路径。数据库仅保存真实抓取的条目、采集状态和关注列表。演示条目不入库，使用固定的 2026-01-15 时间和明确的虚构来源。面板最多分析最近 2,000 条记录；这不是全历史检索或完整回测系统。

源目录位于 `app/sources.py`。当前环境需要允许目录中指定的官方 HTTPS 域名。添加来源时先确认使用条款、许可、发布时间语义、原始作者与转载关系，并注册精确主机名；浏览器不会代理任意用户提供的 URL。

所需来源主机：`www.federalreserve.gov`、`www.ecb.europa.eu`、`www.bankofengland.co.uk`、`www.bis.org`、`www.boj.or.jp`、`www.sec.gov`、`export.arxiv.org`、`rss.arxiv.org`。云环境的安装脚本、启动说明及来源网络设置已保存到配置草稿；审核保存并发布环境后，后续任务才能使用发布的快照。当前完成验证不等于已经发布。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/dashboard?mode=live` | 实时库聚合结果，空库保持为空 |
| `GET /api/dashboard?mode=demo` | 明确标识的虚构演示数据 |
| `POST /api/ingest` | `{}` 同步启用来源，或 `{"source_ids":["来源 ID"]}` |
| `GET /api/watchlist` | 读取关注资产 |
| `POST /api/watchlist` | 保存 symbol/name/asset_class/region/note |
| `DELETE /api/watchlist/{id}` | 删除关注项 |
| `GET /api/export?mode=live` | 导出当前主题摘要 |
| `GET /api/health` | 应用和数据库就绪检查 |

## 进一步完善

准确性优先的扩展路线见 [docs/ROADMAP.md](docs/ROADMAP.md)。测试覆盖去重边界、来源独立性、RSS/Atom 解析、数据隔离、输入校验、关注项持久化、导出和采集失败行为。单元测试不证明外部源当前可达，真实联网结果以“数据来源”页为准。
